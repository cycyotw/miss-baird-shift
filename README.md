# Miss Baird: SHIFT

An entry for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026) (theme: SHIFT).

Work in progress.

## Run locally

Plain HTML/CSS/JS, no build step, no dependencies. Serve this folder with any static server, e.g.

```
python3 -m http.server 8000
```

and open http://localhost:8000. Append `?mute` to the URL to run without sound.

## Layout

- `index.html`, `style.css` — page and stage
- `engine/` — game engine (written for this jam)
- `data/` — settings and text tables (`text.en.js` / `text.zh.js`, same keys)
- `assets/` — images, audio, fonts
